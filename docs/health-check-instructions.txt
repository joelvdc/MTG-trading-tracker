Weekly check for two Android apps by joelvdc that depend on outside services and card data:
- MTG Trader: https://github.com/joelvdc/MTG-trading-tracker
- Poké Trader: https://github.com/joelvdc/PokemonTCG-trading-tracker
Both repositories are checked out in this session.

Three goals: (A) find out early if a service the apps use has changed in a way that would break them, (B) spot new card releases (new sets, card types, finishes, layouts, rarities, mechanics, set-code formats) that the apps' code doesn't handle yet, and (C) spot changes to the Commander rules that MTG Trader's life tracker counts on.

Rules: only read. Never log in, never post or change anything anywhere (no commits, no pull requests, no issues), and keep requests few and slow: at most one request per second per site. The one exception is publishing this run's own report as a private page (see "Publish" at the end). Use the header "User-Agent: MTGTraderAndroid/1.0" for MTG services (Scryfall rejects default user agents) and "User-Agent: PokeTraderAndroid/1.0" for Pokémon services (TCGdex needs a named one).
