# 1.78: free from the Archidekt login, CSV for Archidekt, change printing
- **Before installing:** on 1.77, run a last Archidekt collection sync (Settings → Archidekt collection) and let any deck edits that are waiting go out. 1.78 no longer syncs with Archidekt.
- **No more Archidekt login:** the app reads public Archidekt decks only, and only when you tap (adding a deck, Reload decklist, Update all decks). The collection sync, sending deck edits, "Send to Archidekt" and folder/visibility are gone, and the saved Archidekt login is removed from the phone. Settings → Archidekt keeps your username so your own decks are still recognised (filled in from the old login).
- **Archidekt decks are read only:** edit them on archidekt.com, then reload them (⟳). To change one in the app, ⋮ → Make it a local deck. A deck with changes that never reached Archidekt says so, with Make it a local deck (keeps them) or Discard; reloading such a deck asks first.
- **Export CSV asks for the format:** MTG Trader (full), or Archidekt (for Archidekt's importer with the "ManaBox – Single folder" preset). For Archidekt: everything, or only the cards added since this phone's last export (new cards and extra copies; remove cards on Archidekt by hand). Check the first file with a small import.
- **Change printing on wishlist cards:** the card's window has Change printing, to pick another printing of the same card (also on the website).
