# 1.108: Active decks in games, a calmer Sort screen
- **Games**: choosing a deck for a seat offers only your active decks (your own Archidekt decks and local decks, not retired). Decks of other Archidekt users no longer show up there. Phone and website.
- **Sort screen with less text**: the binder counts, "7/10 this week" with **Sort all now**, the moves, and a short "no room" count. The settings keep only their labels. Phone and website.
- **Settings… from the sort's setup**: the menu no longer offers Settings… while you're already in them, and Back returns to the suggestions.
- **Decks binder on by default** in the sort's settings (a binder already called "Decks" is used).
- **Fixes**: "Unless ×" showed "3," on phones set to Danish and other languages; the labels under "How cards are weighed" overlapped. The sort is worked out in the background, so the screen stays responsive with a big collection.
