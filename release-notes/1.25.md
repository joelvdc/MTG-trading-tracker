# 1.25: collection value per binder, tidier color chart
- **Value over time per binder:** the collection value screen has chips at the top, like the stats screen: all cards, Unsorted or one binder. The chart, the total and the rising/falling cards follow the choice. Binder values are saved from this version on, so a binder's chart starts today.
- **Color chart in the stats:** the amounts and percentages next to the pie now line up in neat columns. In "Charts by value" they're shown without cents, so long names like "Multicolor" and big amounts fit, also with bigger text on the phone.

`MTG-Trader-1.25.apk` is for 64-bit ARM phones; use `MTG-Trader-1.25-universal.apk` if it won't install. Installs over any earlier version and keeps your data.
