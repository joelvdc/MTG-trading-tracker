# 1.96: search inside a deck, copy and paste deck lists
- **Search inside a deck**: the 🔍 icon at the top of a deck's page opens a search field. It takes Scryfall's search words, the same as the website's deck filter: `t:creature`, `o:draw`, `c:rg`, `mv<=2`, `is:commander`, `cat:ramp`, `-t:land`, `or`, brackets and quotes. While you search, the page shows only the matching cards, with "N of M cards" under the field. A few words only Scryfall itself knows (such as `otag:` and `art:`) aren't searched in the app; it says so. The phone and the website check the same 164 test searches, so they give the same answers.
- **Copy deck as text** (⋮ → Share): the deck in Moxfield, Archidekt, MTG Arena or plain-list format, with or without categories and the maybeboard; copy it or share it. It's the same text the website writes, and it can be pasted back into either site or into the app.
- **Paste cards** into one of your own decks (⋮ → Deck): paste a list, choose the deck or the maybeboard, then Check. It shows how many cards will be added, which ones are already in the deck (they're skipped, except basic lands, whose copies are added) and which ones Scryfall didn't find. Undo takes the whole paste back.
- **The ⋮ menu on a deck's page is grouped** under Deck, View, Share and More, with Retire and Delete at the bottom.
- On the website since 1.95 (no app update needed): the deck page has fewer buttons, an Undo bar for every deck change, Select mode to change many cards at once, Copy deck as text, Paste cards, a playtester, and a more compact scores card and toolbar.
