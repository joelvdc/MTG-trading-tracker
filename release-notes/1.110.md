# 1.110: Done in the sort is fast again
- **Sort the collection → Done**: a big sort (thousands of moves, such as the first one into the Decks binder) took minutes with no sign of progress. It now takes seconds, and the button shows "Moving…" while it works.
- **Leaving the screen** while the sort or the trade binder is moving cards no longer cancels it; the moves finish in the background.
- **Trade binder → Apply** is faster the same way.
