# 1.102: "In no deck." on the card page
- **In no deck**: when you open a card from your collection, the card page now also says "In no deck." when none of your decks use it (it already listed the decks that do). Basic lands get no note, as before.
- **On the website (already live)**:
  - In the bar for selected cards, **Move to…** now ends with **New binder…**: give it a name and the selected cards move straight into the new binder.
  - The toolbar's **Collection ▾** menu is now called **More ▾** (Stats, Trade binder, Import, Export, Print, Share).
  - Export → Archidekt now tells you how to import it: on archidekt.com, Collection → Import → the "ManaBox – Single folder" preset.
  - The **Scanned** list is always shown next to All and Wishlist, also when it has 0 cards.
- No sync change: phones on 1.97 and later keep syncing.
