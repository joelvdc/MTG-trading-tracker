# 1.30: Card Kingdom prices fixed, download bar
- **Card Kingdom works again:** Card Kingdom refuses some phones (it answered "HTTP 403"). The app now falls back to a copy of Card Kingdom's daily price list that GitHub keeps for it, so its prices download wherever you are.
- **TCGplayer once a day:** TCGplayer's prices were downloaded every time the app opened, because Card Kingdom kept failing. Each source now has its own daily download, and after a failed try the app waits a few hours before trying again.
- **Download bar:** like Cardmarket's, a bar above the tabs shows TCGplayer's and Card Kingdom's downloads with their progress, and a note if one failed.
- **Settings → Price source** shows when each source last downloaded (and where Card Kingdom's came from), and each one's own error if it failed.

`MTG-Trader-1.30.apk` is for 64-bit ARM phones; use `MTG-Trader-1.30-universal.apk` if it won't install. Installs over any earlier version and keeps your data.
