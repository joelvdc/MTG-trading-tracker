# 1.92: steadier sync
- **An edit made while a sync is saving is no longer missed.** Before, a change made in that split second could be counted as already sent, and only went out at the next app start, when the app went to the background, or with the hourly sync.
- **Changes made while a sync is running start the next sync by themselves** (about 30 seconds later), instead of waiting for one of those moments.
- **An unexpected error during a sync shows as a message** under Settings → Sync instead of closing the app, and other background work is protected the same way.
- Behind the scenes: tests for the sync itself; GitHub now also checks the website on every change, and a release stops if it would be signed with a different certificate than the one before (phones wouldn't install it). The website refuses a sync save that doesn't say which version it replaces, and no longer skips a deploy when the last commit of a push didn't touch the website.
