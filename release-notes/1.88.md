# 1.88: "Last modified" sorts local decks too
- **Decks tab:** the sort option "Last modified on Archidekt" is now just **"Last modified"**. Local decks now get sorted by date too, inside their own Local section (they used to sit at the bottom in name order).
- A local deck's date is the last time it changed in the app or on the website. Any change counts, a re-score too. While this sort is on, the date shows under each local deck as "Changed <date>"; Archidekt decks still show the date Archidekt gives.
- **Website:** the same on the Decks page.
