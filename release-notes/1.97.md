# 1.97: deck primers, card notes, your own tags, packages and change history
- **Update every phone**: this version changes the sync file (format 15). A phone still on 1.96 pauses syncing until it is updated.
- **Primer**: every deck can have a primer, its game plan in your own words (⋮ → Deck → Primer…, or the Primer card under the deck's header). Headings (`# `), bullets (`- `) and **bold** (`**text**`) are shown as such. It works on every deck, also decks from Archidekt: reloading the list keeps it, and a deck that has a description on Archidekt takes it as its primer once, if it has none yet.
- **Card notes**: a short note per card (in the card's window), marked with a note icon in the list.
- **Your own tags**: tag a card once (Sol Ring = Ramp, or anything you like, such as "Combo piece") and the tag counts in every deck. Cards you haven't tagged use the automatic roles the website already works out and the deck's own categories. Tag many cards at once from a selection.
- **Role counts**: a line under each deck's header such as "Lands 37 · Ramp 11 · Draw 9 · Removal 8 · Wipes 3", coloured against common guidelines (orange when below or above). Tap a role to see its cards; `tag:ramp` works in the deck search.
- **Packages**: save a group of cards (a combo, a mana base) from a selection or from pasted text, then add it to a local deck (only the cards it doesn't have yet) or take it out again, with Undo. Each package shows which decks use it (⋮ → Deck → Packages…).
- **Change history**: what was added to and removed from a deck, per day, and whether it was in the app, on the website or by an Archidekt reload (⋮ → Change history). It starts with this version and keeps the last 100 days with changes.
- On the website too: the same primer, notes, tags, role counts, packages and history; in Select mode, "Tag…" and "Save as package…"; shared deck links show the primer and the card notes.
