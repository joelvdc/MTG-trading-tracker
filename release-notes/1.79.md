# 1.79: sync with your MTG Trader account
- **MTG Trader account:** Settings → Sync → MTG Trader account logs in with the account made on the website (mtgtrader.vercel.app → Settings → Make my account and copy my data), or makes a new one with an invite code from the owner. The phone then syncs with the account, the same way it did with Nextcloud, and the website shows the same data.
- **Moving over from Nextcloud:** Settings → Sync → Switch to my MTG Trader account. The first sync merges, or asks what to keep when this phone holds something the account doesn't. Nextcloud still gets a backup copy every night from the website; nothing there is deleted.
- **Log out** in Settings → Sync stops syncing this phone; the website lists every device logged in to the account and can log them out.
- **The trade binder syncs:** which binder is the trade binder now follows to your other phones and the website.
- Settings that only a newer version knows are no longer dropped when a phone on an older version syncs.
